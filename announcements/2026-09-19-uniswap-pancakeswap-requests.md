# AQT listing requests submitted to Uniswap and PancakeSwap

**19 September 2026 — 210 CodeLabs**

The AQT project has submitted public review requests for the Ethereum token to:

- [Uniswap default token list — issue #2585](https://github.com/Uniswap/default-token-list/issues/2585)
- [PancakeSwap token list — issue #756](https://github.com/pancakeswap/token-list/issues/756)

The requests include the verified contract, official logo, website, public source and ABI, Safe ownership information, liquidity pair, and onchain trading evidence.

These are **pending review requests**, not confirmations of acceptance. Uniswap and PancakeSwap decide independently whether to add the token to their lists. AQT remains tradable by using the verified contract address directly:

`0x4F57428adbd6F610C4485E7B69102fb462f9b287`

The project will update this announcement if either repository accepts or closes a request.
