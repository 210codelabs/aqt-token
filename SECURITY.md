# Security Policy

## Reporting a security issue

Report suspected vulnerabilities, compromised project infrastructure, malicious impersonation, or incorrect security classifications to:

**ernesto@210codelabs.com**

Include the affected address or URL, network, transaction hashes, reproducible steps, and potential impact. Do not include private keys, seed phrases, wallet backup files, or other signing credentials.
